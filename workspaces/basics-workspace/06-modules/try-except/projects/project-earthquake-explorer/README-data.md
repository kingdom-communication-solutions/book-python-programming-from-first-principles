# Data for the Earthquake Explorer

- `earthquakes-m4.5-30-days.json`: the 722 earthquakes of magnitude 4.5 and above in the 30 days before 3 November 2026, saved from the U.S. Geological Survey feed (U.S. public domain; credit the U.S. Geological Survey). Source and checksums: `datasets/usgs-earthquakes/provenance.json` in the book repository.
- `earthquakes-truncated-copy.json`: **made for the exercise**. It is the first 3,000 characters of the file above, cut off in the middle of a record, to imitate a download that was interrupted. The real records are all complete.
