# Basics workspace: Python Programming from First Principles

This folder contains Getting Started and Python Basics, including Modules, as notebooks you can run on your
own computer: one notebook per runnable listing and one per mini project, project and Coding Challenge.

## Set up once

1. Install Python as described in Getting Started in the book. Anaconda includes Jupyter.
2. Open a terminal in this folder and start Jupyter with `jupyter notebook`. With a python.org installation,
   first create an environment and install Jupyter:
   - macOS, Linux: `python3 -m venv .venv`, `source .venv/bin/activate`, `python -m pip install notebook`
   - Windows: `py -m venv .venv`, `.venv\Scripts\activate`, `python -m pip install notebook`

## Work with the notebooks

- Open a notebook in Jupyter, VS Code or PyCharm and run the cells from the top.
- Programs that read the keyboard with `input()` ask for your answers below the cell, as in a terminal.
- In Getting Started, `%%writefile` cells save your program as a file and `%run` cells run it. You can also
  run such a file from a terminal with `python greetings.py`.

Solutions are not included. The same notebooks open online at code.kcslab.org.
