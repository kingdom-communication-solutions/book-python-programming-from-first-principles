# Advanced workspace: Python Programming from First Principles

This folder contains the Advanced Python part of the book as notebooks you can run on your own computer:
one notebook per runnable listing and one per exercise, Coding Challenge and project. Each project folder
also holds the project's own files, such as data and starter programs.

## Set up once

1. Install Python 3.10 or later (see Getting Started in the book). Anaconda includes Jupyter.
2. Open a terminal in this folder and install the packages: `python -m pip install -r requirements.txt`.
   Some sections use `requests`, `beautifulsoup4` and `pytest`; the file installs them.
3. Start Jupyter with `jupyter notebook`, or open the folder in VS Code.

## Run the code

- A notebook: open it and run the cells from the top.
- A project: open a terminal in its folder and run the command given in the book, such as
  `python museum.py` or `python -m pytest`.
- Examples with threads, processes, files or web requests run best on your computer, not in the browser.

Solutions are not included.
