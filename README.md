# Python Programming from First Principles — Companion Files

Learner code, notebooks, starter projects and datasets for *Python Programming from First Principles: Learn to Code, Think Computationally, and Solve Real-World Problems*, by Philippe Tamla.

## Download and start

1. Select **Code → Download ZIP** on this repository and extract the archive. Download the complete folder rather than opening individual Python or data files in the browser.
2. Install Python 3.10 or later. Follow the installation chapter of the book; Anaconda users already have Jupyter.
3. Open a terminal in the workspace you need. Create and activate a virtual environment when appropriate, then install that workspace's `requirements.txt`.
4. To open notebooks, install Jupyter if necessary with `python -m pip install notebook`, then run `jupyter notebook`. Open the `.ipynb` file and run its cells from the top. JupyterLab or VS Code with notebook support can also open these files.
5. Run `.py` programs from their project folder, using the command given in the book. Keep data files beside the associated project and preserve the folder structure.

The downloaded notebooks use your local Python kernel. Programs with `input()` ask for input normally; browser-only `typed_answers` helpers are not needed. Some lessons deliberately demonstrate exceptions or incomplete starter code. An expected error in an exercise is not a broken download.

## Workspaces

- [Basics](workspaces/basics-workspace): Getting Started, fundamentals, collections, control flow, functions and modules.
- [Object-oriented programming](workspaces/oop-workspace): classes, the Library checkpoints, UML activities and the University Course System starter project.
- [Advanced Python](workspaces/advanced-workspace): files, testing, concurrency, web data and the museum collection project.

Each workspace has its own README and setup instructions. Project notebooks, datasets and starter programs are grouped with their associated activity. Instructor solutions are not included.
